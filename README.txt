The new version downloads candidate GIFs, verifies the GIF87a/GIF89a file signature, caches the bytes in bounded memory, and serves them from your Render HTTPS URL at /gif/<id>.gif so Telegram fetches the media from your bot rather than directly from the original host. The cache is in-memory and is cleared on service restart; search again after a restart. Files larger than 8 MB are skipped to protect the free instance. Google API credentials remain optional.
