Replace the bot.py in your GitHub repository with this bot.py. Your Render Start Command in the supplied render.yaml is python bot.py. If you prefer main.py, change the Render Start Command to python main.py. Keep your existing Render environment variables. The updated bot checks the first bytes of each candidate URL for GIF87a/GIF89a and omits untrusted width/height metadata to prevent static images and broken aspect-ratio metadata from being sent as GIF results. Google credentials are optional; without them DuckDuckGo is used.
